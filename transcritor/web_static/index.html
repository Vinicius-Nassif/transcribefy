Transcritor de Sessões

Envie a gravação do OBS, diga quem fala em cada faixa de áudio e receba uma transcrição única, com cada fala atribuída a quem a disse.

1 Gravação

Arraste o arquivo para cá, ou escolha no computador

A gravação do OBS, de preferência em MKV ou MP4, com cada fonte de som numa trilha (o microfone do GM numa, o Discord noutra). O arquivo é copiado para o servidor; a cópia é apagada quando a transcrição termina.

Para gravações longas, a linha de comando evita copiar o arquivo inteiro.

2 Quem fala em cada faixa Uma faixa é uma trilha de áudio do arquivo. Marque "uma pessoa" para um microfone individual: as falas recebem o nome dela, sem análise de voz. Marque "várias pessoas" para uma trilha compartilhada, como o Discord: as vozes são separadas pelo timbre. Só as faixas listadas aqui são transcritas.

Começa com o arranjo de sempre: o GM na faixa 1 e os jogadores na faixa 2.

3 Reconhecimento

O modelo que reconhece a fala. Os Whisper ("preciso", "rapido", "leve") pontuam e aceitam o contexto da mesa; o "preciso" é o melhor e pede GPU para ser rápido. Modelos ainda não baixados são baixados na primeira vez.
O idioma falado na gravação. Informar acerta mais que detectar: a detecção olha só os primeiros segundos. Também é o idioma de origem da tradução.
Nomes próprios, lugares e jargão que aparecem na sessão — é onde o reconhecimento mais erra. Adicione um termo por item; um item também pode ser uma frase inteira, como "Campanha de Ravenloft, em Barovia". Os nomes das faixas já entram sozinhos. Os termos ficam guardados neste computador e voltam como sugestão.
